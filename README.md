# Floyd Rose 🎸

A beautiful, high-tech, deeply immersive system-wide theme based on the band **Pink Floyd**, tailored specifically for Linux lovers, guitar players, tech geeks, and readers of **Techaeris**!

Named after the legendary double-locking guitar tremolo system, **Floyd Rose** offers a premium, darker-but-vibrant visual identity built for the [Omarchy](https://omarchy.org/) Linux distribution.

---

*   **Refractive Palette (`colors.toml`):** Pitch black celestial space-like backgrounds with high-intensity glowing neon accents (including hot-pink `#ff2e93` and refraction-prism rainbow hues).

## 🚀 Easy Installation

Omarchy makes installing custom themes incredibly easy! Simply run the following command in your terminal:

```bash
omarchy theme install https://github.com/techaeris/floyd-rose
```

Then, set it as active:

```bash
omarchy theme set floyd-rose
```

---

## 🎨 Theme Commands

Once installed, you can use these commands to interact with the theme:

*   **Cycle Backgrounds:**
    ```bash
    omarchy theme bg next
    ```
*   **Check Active Theme:**
    ```bash
    omarchy theme current
    ```
*   **Show About System Logo:**
    ```bash
    fastfetch
    ```
